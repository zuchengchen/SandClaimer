领取规则（按套餐区分）

  • 免费 Free 账号：领取 Sand 需要自行手动绑定信用卡。点该账号那一行的「网页领取」，会用它的登录态打开浏览器直接到领取页，你在浏览器里完成绑卡即可。
  • Pro / Pro+ / Ultra / Team 账号：无需绑卡，直接点「领取」或「批量领取」即可开通。

常用操作

  • 导入账号：粘贴 access_token / ws token（每行一个），或「导入文件」选 cursor_accounts_*.json。账号与状态都会自动保存，下次打开无需重导。
  • 批量领取：可设「并发」数并行领取；勾选部分账号则只处理勾选的，不勾则处理全部。
  • 刷新状态：查询每个账号的套餐、Sand 状态与额度。
  • 自动刷新周用量：勾选后每隔 1 分钟在后台静默重新查询所有账号的 Bot 周用量并更新列表（批量领取/刷新进行中会自动跳过）；取消勾选即停止，设置会记住。
  • 两个账号：每行的「Bot 周用量」对应该行账号；顶部「当前 Cursor」和行内蓝色标记表示桌面客户端正在使用的账号。身份以 access token 的 user id 为准，不要以旧邮箱缓存判断。切号后重新点「探测本机账号」即可复核。
  • 本机 Cursor 补丁：给本机 Cursor 打 / 回退 Sand 客户端模式补丁。
